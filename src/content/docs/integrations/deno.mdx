<h1 id="_top">Integration with Deno</h1>

Elysia is built on top of Web Standard Request/Response, allowing us to run Elysia with Deno.serve directly.

Add Elysia to your Deno project with `deno add npm:elysia@2.0.0-beta.32`. Then pass `app.fetch` to `Deno.serve`:

```typescript
import { Elysia } from 'elysia'

const app = new Elysia()
	.get('/', () => 'Hello Elysia')

Deno.serve(app.fetch)
```

Then run the module with network permissions:
```bash
deno run --allow-net --watch src/index.ts
```

This is all you need to run Elysia on Deno.

### Change the port number
You can specify the port number in `Deno.serve`.

```ts
Deno.serve({ port: 8787 }, app.fetch)
```

### pnpm
If your pnpm configuration does not install peer dependencies, add the peers required by Elysia v2 explicitly:
```bash
pnpm add typebox exact-mirror openapi-types
```
