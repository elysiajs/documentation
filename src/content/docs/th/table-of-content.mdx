### Agentic Coding

Elysia มี `llms.txt` และ skill สำหรับ AI agent อย่าง **Claude Code** และ **OpenCode** ให้ใช้ เลือกเวอร์ชันของ skill ให้ตรงกับเวอร์ชัน Elysia ในโปรเจกต์ของคุณ

```
bunx skills add elysiajs/skills
```
