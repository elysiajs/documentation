### Agentic Coding

Elysia มี `llms.txt` และ skill สำหรับ AI agent อย่าง **Claude Code** และ **OpenCode** ให้เลือกเวอร์ชันของ skill ให้ตรงกับเวอร์ชันของ Elysia ในโปรเจกต์ของคุณ

```
bunx skills add elysiajs/skills
```
