<h1 id="_top">Fullstack dev server ของ Bun</h1>

[fullstack dev server](https://bun.com/docs/bundler/fullstack) ของ Bun จะ bundle asset ฝั่ง frontend ให้ และรองรับ hot module replacement (HMR) คู่มือนี้ใช้ Bun 1.3 ขึ้นไป และ static plugin ของ Elysia v2

เราเลยใช้ React ได้โดยตรง ไม่ต้องพึ่ง bundler อย่าง Vite หรือ Webpack

## ตั้งค่าเซิร์ฟเวอร์

ติดตั้ง static plugin ของ Elysia v2:

```bash
bun add elysia@rc @elysia/static@next react react-dom
bun add -d @types/react @types/react-dom
```

:::tip

ตั้ง `bunFullstack: true` และ await `staticPlugin()` ก่อนเริ่มเซิร์ฟเวอร์ โดยค่าเริ่มต้น plugin นี้จะ serve ไฟล์ static แบบธรรมดา แค่ await อย่างเดียวจะไม่ได้เปิดใช้ HTML bundler

:::

</InteractiveStep>

### เปิดใช้ JSX

เปิดใช้ JSX ใน `tsconfig.json`

เปิด `http://localhost:3000/public` แล้วดูผลลัพธ์ได้เลย

Bun จัดการ bundle ฝั่ง frontend ไปพร้อมกับ API เลย จึงไม่ต้องรัน process ของ bundler แยก

ตัวอย่างต้นฉบับรวม HMR, [Tailwind](#tailwind-css), TanStack Query, [Eden Treaty](/eden/) และ path alias ไว้ด้วยกัน ใช้เวอร์ชันที่เข้ากันได้กับ Bun และ Elysia รุ่นที่คุณใช้อยู่

เราเปลี่ยน prefix เริ่มต้น `/public` ได้ด้วยการส่งตัวเลือก `prefix` ให้ `staticPlugin`

## Build สำหรับ production

build เซิร์ฟเวอร์ fullstack ได้เหมือนเซิร์ฟเวอร์ Elysia ปกติเลย

```bash
bun build --compile --target bun --outfile server src/index.ts
```

คำสั่งนี้จะสร้างไฟล์ executable ชื่อ `server` อย่าลืมทดสอบ build ของ production ด้วย ไม่ใช่แค่ HMR ตอน development

ตอนรัน executable **server** อย่าลืมเอาโฟลเดอร์ **public** ไปด้วยเหมือนตอน development

ดูรายละเอียดเพิ่มเติมได้ที่ [Deploy ขึ้น production](/patterns/deploy)
