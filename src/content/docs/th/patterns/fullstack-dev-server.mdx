<h1 id="_top">Bun fullstack dev server</h1>

[fullstack dev server](https://bun.com/docs/bundler/fullstack) ของ Bun ช่วย bundle asset ฝั่ง frontend และรองรับ hot module replacement (HMR) คู่มือนี้ใช้ Bun 1.3 ขึ้นไปและปลั๊กอิน static ของ Elysia v2

ทำให้เราใช้ React ได้ทันทีโดยไม่ต้องมี bundler อย่าง Vite หรือ Webpack

## ตั้งค่าเซิร์ฟเวอร์

ติดตั้งปลั๊กอิน static ของ Elysia v2:

```bash
bun add elysia@rc @elysia/static@next react react-dom
bun add -d @types/react @types/react-dom
```

:::tip

ตั้งค่า `bunFullstack: true` และ await `staticPlugin()` ก่อนเริ่มเซิร์ฟเวอร์ โดยค่าเริ่มต้นปลั๊กอินจะให้บริการไฟล์ static แบบปกติ การ await อย่างเดียวไม่ได้เปิดใช้ HTML bundler

:::

Bun จัดการ bundle ฝั่ง frontend ไปพร้อมกับ API คุณจึงไม่ต้องมี process ของ bundler แยก

ตัวอย่างต้นฉบับรวม HMR, [Tailwind](#tailwind-css), TanStack Query, [Eden Treaty](/eden/) และ path alias ไว้ด้วยกัน ให้ใช้เวอร์ชันที่เข้ากันได้กับ Bun และ Elysia ที่คุณใช้

## Build สำหรับ production

คุณ build เซิร์ฟเวอร์แบบ fullstack ได้เหมือนกับเซิร์ฟเวอร์ Elysia ทั่วไป

```bash
bun build --compile --target bun --outfile server src/index.ts
```

คำสั่งนี้จะสร้างไฟล์ executable ชื่อ `server` ควรทดสอบทั้ง production build และ HMR ตอนพัฒนา

เมื่อรันไฟล์ executable **server** อย่าลืมใส่โฟลเดอร์ **public** ไว้ด้วยเหมือนในสภาพแวดล้อมตอนพัฒนา

ดูข้อมูลเพิ่มเติมได้ที่ [Deploy ขึ้น production](/patterns/deploy)
