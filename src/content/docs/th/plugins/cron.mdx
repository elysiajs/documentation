<h1 id="_top">Plugin Cron</h1>

plugin นี้ช่วยให้รัน cron job บนเซิร์ฟเวอร์ Elysia ได้

ติดตั้งด้วยคำสั่ง:

```bash
bun add @elysia/cron@rc
```

จากนั้นก็นำไปใช้ได้เลย:

```ts
import { Elysia } from 'elysia'
import { cron } from '@elysia/cron'

new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: '*/10 * * * * *',
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.listen(3000)
```

โค้ดนี้จะ log `Heartbeat` ทุก ๆ 10 วินาที

## cron

สร้าง cron job ให้เซิร์ฟเวอร์ Elysia

type:

```text
cron(config: CronConfig): (app: Elysia) => Elysia
```

`CronConfig` รับ parameter ตามรายการด้านล่างนี้:

### name

ชื่อของ job ที่จะลงทะเบียนไว้ใน `store`

ระบบจะลงทะเบียน instance ของ cron ไว้ใน `store` ตามชื่อที่ตั้ง เพื่อให้อ้างถึงได้ในขั้นตอนหลังจากนี้ เช่น ตอนจะหยุด job

### pattern

เวลาที่จะให้ job ทำงาน เขียนตาม[ไวยากรณ์ของ cron](https://en.wikipedia.org/wiki/Cron) ด้านล่างนี้:

```text
┌────────────── second (optional)
│ ┌──────────── minute
│ │ ┌────────── hour
│ │ │ ┌──────── day of the month
│ │ │ │ ┌────── month
│ │ │ │ │ ┌──── day of week
│ │ │ │ │ │
* * * * * *
```

จะใช้เครื่องมืออย่าง [Crontab Guru](https://crontab.guru/) ช่วยสร้างก็ได้

### run

ฟังก์ชันที่จะรันทุกครั้งที่ job ถึงเวลาทำงาน

---

plugin นี้ลงทะเบียน job ตามตารางเวลาด้วย [Croner](https://github.com/hexagon/croner)

ด้านล่างนี้คือตัวเลือกของ Croner ที่รองรับ

### timezone

เขตเวลาในรูปแบบ Europe/Stockholm

### startAt

เวลาเริ่มต้นของ job

### stopAt

เวลาสิ้นสุดของ job

### maxRuns

จำนวนครั้งสูงสุดที่จะให้ทำงาน

### catch

ให้ทำงานต่อไปแม้ฟังก์ชันที่ถูกเรียกจะโยน error ที่ไม่ได้จัดการออกมา

### interval

ระยะห่างขั้นต่ำระหว่างการทำงานแต่ละครั้ง หน่วยเป็นวินาที

## รูปแบบการใช้งาน

ด้านล่างนี้คือรูปแบบการใช้ plugin ที่พบบ่อย

## หยุด cron job

หยุด cron job เองได้ด้วยการเข้าถึง cron job ผ่านชื่อที่ลงทะเบียนไว้ใน `store`

```ts
import { Elysia } from 'elysia'
import { cron } from '@elysia/cron'

const app = new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: '*/1 * * * * *',
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.get(
		'/stop',
		({
			store: {
				cron: { heartbeat }
			}
		}) => {
			heartbeat.stop()

			return 'Stop heartbeat'
		}
	)
	.listen(3000)
```

## Pattern สำเร็จรูป

คุณ import `Patterns` จาก `@elysia/cron` มาใช้ได้เลย

```ts
import { Elysia } from 'elysia'
import { cron, Patterns } from '@elysia/cron'

const app = new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: Patterns.everySecond(),
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.get(
		'/stop',
		({
			store: {
				cron: { heartbeat }
			}
		}) => {
			heartbeat.stop()

			return 'Stop heartbeat'
		}
	)
	.listen(3000)
```

### ฟังก์ชัน

| ฟังก์ชัน                                 | คำอธิบาย |
| ---------------------------------------- | ----------------------------------------------------- |
| `.everySeconds(2)`                       | รันงานทุก 2 วินาที |
| `.everyMinutes(5)`                       | รันงานทุก 5 นาที |
| `.everyHours(3)`                         | รันงานทุก 3 ชั่วโมง |
| `.everyHoursAt(3, 15)`                   | รันงานทุก 3 ชั่วโมง ที่นาทีที่ 15 |
| `.everyDayAt('04:19')`                   | รันงานทุกวันเวลา 04:19 |
| `.everyWeekOn(Patterns.MONDAY, '19:30')` | รันงานทุกวันจันทร์เวลา 19:30 |
| `.everyWeekdayAt('17:00')`               | รันงานทุกวันจันทร์ถึงศุกร์เวลา 17:00 |
| `.everyWeekendAt('11:00')`               | รันงานทุกวันเสาร์และอาทิตย์เวลา 11:00 |
