<h1 id="_top">ปลั๊กอิน Cron</h1>

ปลั๊กอินนี้ช่วยให้รัน cron job ในเซิร์ฟเวอร์ Elysia ได้

ติดตั้งด้วยคำสั่ง:

```bash
bun add @elysia/cron@rc
```

จากนั้นนำไปใช้:

```ts
import { Elysia } from 'elysia'
import { cron } from '@elysia/cron'

new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: '*/10 * * * * *',
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.listen(3000)
```

โค้ดนี้จะ log `Heartbeat` ทุก 10 วินาที

## cron

สร้าง cron job ให้เซิร์ฟเวอร์ Elysia

type:

```text
cron(config: CronConfig): (app: Elysia) => Elysia
```

`CronConfig` รับพารามิเตอร์ตามที่ระบุด้านล่าง:

### name

ชื่อของ job ที่จะลงทะเบียนไว้ใน `store`

ตัวเลือกนี้จะลงทะเบียน instance ของ cron ไว้ใน `store` ด้วยชื่อที่กำหนด เพื่อให้อ้างถึงได้ในภายหลัง เช่น ตอนหยุด job

### pattern

เวลาที่จะรัน job ตาม [syntax ของ cron](https://en.wikipedia.org/wiki/Cron) ดังนี้:

```text
┌────────────── second (optional)
│ ┌──────────── minute
│ │ ┌────────── hour
│ │ │ ┌──────── day of the month
│ │ │ │ ┌────── month
│ │ │ │ │ ┌──── day of week
│ │ │ │ │ │
* * * * * *
```

สร้างได้ด้วยเครื่องมืออย่าง [Crontab Guru](https://crontab.guru/)

### run

ฟังก์ชันที่จะทำงานทุกครั้งที่ job ถูกเรียก

---

ปลั๊กอินนี้ลงทะเบียน job ตามกำหนดเวลาด้วย [Croner](https://github.com/hexagon/croner)

ด้านล่างนี้คือตัวเลือกของ Croner ที่รองรับ

### timezone

time zone ในรูปแบบ Europe/Stockholm

### startAt

เวลาเริ่มของ job

### stopAt

เวลาหยุดของ job

### maxRuns

จำนวนครั้งสูงสุดที่จะรัน

### catch

ทำงานต่อแม้ฟังก์ชันที่ถูกเรียกจะ throw error ที่ไม่มีใครจัดการ

### interval

ระยะห่างขั้นต่ำระหว่างการรันแต่ละครั้ง หน่วยเป็นวินาที

## Pattern

ด้านล่างนี้คือรูปแบบการใช้งานปลั๊กอินที่พบบ่อย

## หยุด cron job

คุณหยุด cron job เองได้ด้วยการเข้าถึงชื่อของ cron job ที่ลงทะเบียนไว้ใน `store`

```ts
import { Elysia } from 'elysia'
import { cron } from '@elysia/cron'

const app = new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: '*/1 * * * * *',
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.get(
		'/stop',
		({
			store: {
				cron: { heartbeat }
			}
		}) => {
			heartbeat.stop()

			return 'Stop heartbeat'
		}
	)
	.listen(3000)
```

## Pattern ที่กำหนดไว้ให้

คุณ import `Patterns` จาก `@elysia/cron` ได้

```ts
import { Elysia } from 'elysia'
import { cron, Patterns } from '@elysia/cron'

const app = new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: Patterns.everySecond(),
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.get(
		'/stop',
		({
			store: {
				cron: { heartbeat }
			}
		}) => {
			heartbeat.stop()

			return 'Stop heartbeat'
		}
	)
	.listen(3000)
```

### ฟังก์ชัน

| ฟังก์ชัน                                 | คำอธิบาย                                           |
| ---------------------------------------- | ----------------------------------------------------- |
| `.everySeconds(2)`                       | รันทุก 2 วินาที                          |
| `.everyMinutes(5)`                       | รันทุก 5 นาที                          |
| `.everyHours(3)`                         | รันทุก 3 ชั่วโมง                            |
| `.everyHoursAt(3, 15)`                   | รันทุก 3 ชั่วโมง ที่นาทีที่ 15              |
| `.everyDayAt('04:19')`                   | รันทุกวันเวลา 04:19                       |
| `.everyWeekOn(Patterns.MONDAY, '19:30')` | รันทุกวันจันทร์เวลา 19:30                    |
| `.everyWeekdayAt('17:00')`               | รันทุกวันจันทร์ถึงศุกร์เวลา 17:00 |
| `.everyWeekendAt('11:00')`               | รันทุกวันเสาร์และอาทิตย์เวลา 11:00          |
