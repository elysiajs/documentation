Elysia ออกแบบมาให้เป็นโมดูลและมีขนาดเบา

:::note[เวอร์ชันของปลั๊กอิน]

ใช้ปลั๊กอินเวอร์ชันที่ peer dependency ของ Elysia ตรงกับแอปพลิเคชันของคุณ branch ของปลั๊กอินสำหรับ Elysia 2 ใช้เวอร์ชัน prerelease ส่วนปลั๊กอินรุ่นเก่าอาจพึ่ง API ของ Elysia 1 ที่ถูกเอาออกไปแล้ว รายการจากคอมมิวนิตี้ด้านล่างเป็นเพียงรายชื่อ ไม่ได้รับประกันความเข้ากันได้

:::

## ปลั๊กอินจากคอมมิวนิตี้

-   [Create ElysiaJS](https://github.com/kravetsone/create-elysiajs) - สร้างโปรเจกต์ Elysia พร้อมสภาพแวดล้อมได้ง่าย ๆ (ช่วยเรื่อง ORM, Linter และปลั๊กอิน)!
-   [Lucia Auth](https://github.com/pilcrowOnPaper/lucia) - authentication ที่เรียบง่ายและสะอาดตา
-   [Elysia Clerk](https://github.com/wobsoriano/elysia-clerk) - ปลั๊กอิน authentication ของ Clerk แบบไม่เป็นทางการ
-   [Elysia Polyfills](https://github.com/bogeychan/elysia-polyfills) - รันระบบนิเวศของ Elysia บน Node.js และ Deno
-   [Vite server](https://github.com/kravetsone/elysia-vite-server) - ปลั๊กอินที่เริ่มและ decorate dev server ของ [`vite`](https://vitejs.dev/) ทั้งในโหมด `development` และ `production` และให้บริการไฟล์ static (ถ้าจำเป็น)
-   [Vite](https://github.com/timnghg/elysia-vite) - ให้บริการไฟล์ HTML entry พร้อม script ของ Vite ที่ inject ไว้
-   [Nuxt](https://github.com/trylovetom/elysiajs-nuxt) - เชื่อม Elysia เข้ากับ Nuxt ได้ง่าย ๆ!
-   [Remix](https://github.com/kravetsone/elysia-remix) - ใช้ [Remix](https://remix.run/) พร้อมรองรับ `HMR` (ขับเคลื่อนด้วย [`vite`](https://vitejs.dev/))! ปิดคำขอปลั๊กอินที่ค้างมานานมาก [#12](https://github.com/elysiajs/elysia/issues/12)
-   [Sync](https://github.com/johnny-woodtke/elysiajs-sync) - เฟรมเวิร์กซิงก์ข้อมูลแบบ offline-first ขนาดเบา ขับเคลื่อนด้วย [Dexie.js](https://dexie.org/)
-   [Connect middleware](https://github.com/kravetsone/elysia-connect-middleware) - ปลั๊กอินที่ทำให้ใช้ middleware ของ [`express`](https://www.npmjs.com/package/express)/[`connect`](https://www.npmjs.com/package/connect) ใน Elysia ได้โดยตรง!
-   [Elysia HTTP Exception](https://github.com/codev911/elysia-http-exception) - ปลั๊กอิน Elysia สำหรับจัดการ error HTTP 4xx/5xx ด้วย exception class ที่มีโครงสร้าง
-   [Elysia Helmet](https://github.com/DevTobias/elysia-helmet) - ป้องกันแอป Elysia ด้วย HTTP header หลากหลายแบบ
-   [Vite Plugin SSR](https://github.com/timnghg/elysia-vite-plugin-ssr) - ปลั๊กอิน SSR ของ Vite ที่ใช้เซิร์ฟเวอร์ Elysia
-   [OAuth 2.0](https://github.com/kravetsone/elysia-oauth2) - ปลั๊กอินสำหรับ Authorization Flow ของ [OAuth 2.0](https://en.wikipedia.org/wiki/OAuth) รองรับผู้ให้บริการมากกว่า **42** ราย พร้อม **type-safety**!
-   [OAuth2](https://github.com/bogeychan/elysia-oauth2) - จัดการ authorization code flow ของ OAuth 2.0
-   [OAuth2 Resource Server](https://github.com/ap-1/elysia-oauth2-resource-server) - ปลั๊กอินสำหรับตรวจสอบ JWT token จากผู้ให้บริการ OAuth2 กับ JWKS endpoint รองรับการตรวจสอบ issuer, audience และ scope
-   [Elysia OpenID Client](https://github.com/macropygia/elysia-openid-client) - OpenID client ที่สร้างบน [openid-client](https://github.com/panva/node-openid-client)
-   [Rate Limit](https://github.com/rayriffy/elysia-rate-limit) - rate limiter ที่เรียบง่ายและเบา
-   [Elysia Nazli](https://github.com/esbuker/elysia-nazli) - rate limiter ที่ใช้งานง่าย เปลี่ยน store ได้ และมีกฎทั้งแบบ global และแยกราย route
-   [LLMs.txt](https://github.com/opuu/elysia-llms-txt) - สร้าง `/llms.txt` สำหรับเอกสารที่ LLM อ่านง่ายจาก OpenAPI/Swagger
-   [Logysia](https://github.com/tristanisham/logysia) - logging middleware แบบคลาสสิก
-   [Logestic](https://github.com/cybercoder-naj/logestic) - ไลบรารี logging ขั้นสูงที่ปรับแต่งได้สำหรับ ElysiaJS
-   [Logger](https://github.com/bogeychan/elysia-logger) - logging middleware ที่สร้างบน [pino](https://github.com/pinojs/pino)
-   [Elysia Line](https://github.com/KrataiB/elysia-line) - integration ของ LINE Messaging API และ LINE Login สำหรับ Elysia (ครอบ [@line/bot-sdk](https://github.com/line/line-bot-sdk-nodejs) อย่างเป็นทางการ)
-   [Elylog](https://github.com/eajr/elylog) - ไลบรารี logging ออก stdout แบบเรียบง่ายที่ปรับแต่งได้บ้าง
