<h1 id="_top">ปลั๊กอิน Static</h1>

ปลั๊กอินนี้ให้บริการไฟล์และโฟลเดอร์ static สำหรับเซิร์ฟเวอร์ Elysia

ติดตั้งด้วยคำสั่ง:
```bash
bun add @elysia/static@rc
```

จากนั้นนำไปใช้:
```ts
import { Elysia } from 'elysia'
import { staticPlugin } from '@elysia/static'

new Elysia()
    .use(staticPlugin())
    .listen(3000)
```

โดยค่าเริ่มต้น โฟลเดอร์ของปลั๊กอิน static คือ `public` และลงทะเบียนไว้ด้วย prefix `/public`

สมมติว่าโครงสร้างโปรเจกต์ของคุณเป็นแบบนี้:
```text
| - src
  | - index.ts
| - public
  | - takodachi.png
  | - nested
    | - takodachi.png
```

path ที่เข้าถึงได้จะเป็น:
- /public/takodachi.png
- /public/nested/takodachi.png

## Config
ด้านล่างนี้คือการตั้งค่าที่ปลั๊กอินรองรับ

### assets
ค่าเริ่มต้น: `"public"`

path ของโฟลเดอร์ที่จะเปิดให้เข้าถึงเป็น static

### prefix
ค่าเริ่มต้น: `"/public"`

prefix ของ path ที่ใช้ลงทะเบียนไฟล์สาธารณะ

### ignorePatterns
ค่าเริ่มต้น: `['.DS_Store', '.git', '.env']`

รายการไฟล์ที่จะไม่ให้บริการเป็นไฟล์ static

:::caution
รายการที่กำหนดเองจะแทนที่ค่าเริ่มต้น ให้ใส่ `.env` และ `.git` กลับเข้าไปด้วย ไม่อย่างนั้นไฟล์เหล่านี้จะถูกให้บริการออกไป
:::

### staticLimit
ค่าเริ่มต้น: `1024`

เมื่อเปิด [alwaysStatic](#alwaysstatic) ไว้ ปลั๊กอิน static จะลงทะเบียน path ใน Router แบบชื่อ static ได้ไม่เกินจำนวนนี้ ไฟล์ที่เกินจะถูกหาแบบ lazy ตอนมี request เพื่อลดการใช้หน่วยความจำ
เป็นการแลกกันระหว่างหน่วยความจำกับประสิทธิภาพ

### alwaysStatic
ค่าเริ่มต้น: `process.env.NODE_ENV === 'production'`

ถ้าตั้งเป็น true path ของไฟล์ static จะถูกลงทะเบียนใน Router ตอนเริ่มทำงาน โดยไม่เกิน [staticLimit](#staticlimit) ไม่อย่างนั้นไฟล์จะถูกหาแบบ lazy ตอนมี request

### headers
ค่าเริ่มต้น: `{}`

กำหนด header ของ response สำหรับไฟล์

### indexHTML
ค่าเริ่มต้น: `true`

ถ้าเปิดใช้ request ที่ชี้ไปยังไดเรกทอรีจะได้ไฟล์ `index.html` ในไดเรกทอรีนั้น นี่ไม่ใช่ fallback แบบ single-page application ที่รับทุก path ที่ไม่มีอยู่

## Pattern
ด้านล่างนี้คือรูปแบบการใช้งานปลั๊กอินที่พบบ่อย

- [ไฟล์เดียว](#ไฟล์เดียว)

## ไฟล์เดียว
สมมติว่าต้องการคืนไฟล์แค่ไฟล์เดียว ให้ใช้ `file` แทนปลั๊กอิน static
```ts
import { Elysia, file } from 'elysia'

new Elysia()
    .get('/file', file('public/takodachi.png'))
```
