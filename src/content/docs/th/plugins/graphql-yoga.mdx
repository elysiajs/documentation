<h1 id="_top">ปลั๊กอิน GraphQL Yoga</h1>

ปลั๊กอินนี้เชื่อมต่อ GraphQL Yoga เข้ากับ Elysia

ติดตั้งด้วยคำสั่ง:

```bash
bun add @elysia/graphql-yoga@rc
```

จากนั้นนำไปใช้:

```ts
import { Elysia } from 'elysia'
import { yoga } from '@elysia/graphql-yoga'

const app = new Elysia()
	.use(
		yoga({
			typeDefs: /* GraphQL */ `
				type Query {
					hi: String
				}
			`,
			resolvers: {
				Query: {
					hi: () => 'Hello from Elysia'
				}
			}
		})
	)
	.listen(3000)
```

เมื่อเข้า `/graphql` ในเบราว์เซอร์ (GET request) คุณจะเห็น GraphiQL ของเซิร์ฟเวอร์ Elysia ที่เปิดใช้ GraphQL ไว้

ถ้าต้องการ คุณติดตั้ง optional peer dependency เวอร์ชันที่ต้องการเพิ่มได้ด้วย:

```bash
bun add graphql graphql-yoga
```

## Resolver

Elysia ใช้ [Mobius](https://github.com/saltyaom/mobius) อนุมาน type จาก field **typeDefs** ให้อัตโนมัติ คุณจึงได้ type-safety และ auto-complete เต็มรูปแบบเวลาเขียน type ของ **resolver**

## Context

คุณเพิ่ม context ของคุณเองให้ฟังก์ชัน resolver ได้ด้วยการเพิ่ม **context**

```ts
import { Elysia } from 'elysia'
import { yoga } from '@elysia/graphql-yoga'

const app = new Elysia()
	.use(
		yoga({
			typeDefs: /* GraphQL */ `
				type Query {
					hi: String
				}
			`,
			context: {
				name: 'Mobius'
			},
			// Required for resolvers to infer the context type
			useContext(_) {},
			resolvers: {
				Query: {
					hi: async (parent, args, context) => context.name
				}
			}
		})
	)
	.listen(3000)
```

## Config

ปลั๊กอินนี้ขยายมาจาก [ตัวเลือกของ createYoga ใน GraphQL Yoga ดูรายละเอียดในเอกสารของ GraphQL Yoga](https://the-guild.dev/graphql/yoga-server/docs) โดยย้ายการตั้งค่า `schema` ขึ้นมาไว้ที่ระดับราก

ด้านล่างนี้คือการตั้งค่าที่ปลั๊กอินรองรับ

### path

ค่าเริ่มต้น: `/graphql`

endpoint ที่เปิดให้เข้าถึง GraphQL handler
