<h1 id="_top">Integration กับ Netlify Edge Function</h1>

[Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/) รันอยู่บน [Deno](/integrations/deno) ซึ่งเป็นหนึ่งใน runtime ที่ Elysia รองรับ เพราะ Elysia สร้างบนพื้นฐานของ Web Standards

Netlify Edge Functions ต้องวางฟังก์ชันไว้ในโฟลเดอร์เฉพาะถึงจะรันได้ โดยค่าเริ่มต้นคือ **\<directory\>/netlify/edge-functions**

ถ้าจะสร้างฟังก์ชันที่ **/hello** ต้องสร้างไฟล์ `netlify/edge-functions/hello.ts` แล้ว export ฟังก์ชันที่ส่งต่อ request ไปให้ Elysia


```typescript title="netlify/edge-functions/hello.ts"
import { Elysia } from 'elysia'

export const config = { path: '/hello' }

const app = new Elysia({ prefix: '/hello' })
	.get('/', () => 'Hello Elysia')

export default (request: Request) => app.handle(request)
```


### รันบนเครื่อง
ถ้าอยากทดสอบเซิร์ฟเวอร์ Elysia บน Netlify Edge Functions ในเครื่อง ให้ติดตั้ง [Netlify CLI](https://docs.netlify.com/build/edge-functions/get-started/#test-locally) เพื่อจำลองการเรียกฟังก์ชัน

ติดตั้ง Netlify CLI:
```bash
bun add -g netlify-cli
```

รันในโหมด development:
```bash
netlify dev
```

ดูข้อมูลเพิ่มเติมได้ที่ [เอกสาร Netlify Edge Functions](https://docs.netlify.com/build/edge-functions)

### pnpm
ถ้า pnpm ของคุณตั้งค่าไว้ไม่ให้ติดตั้ง peer dependencies อัตโนมัติ ก็เพิ่ม peer ที่ Elysia v2 ต้องใช้เองได้เลย:
```bash
pnpm add typebox exact-mirror openapi-types
```
