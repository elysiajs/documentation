<h1 id="_top">สรุปฉบับย่อ</h1>

สรุปรูปแบบการใช้งาน Elysia ที่เจอบ่อยแบบรวบรัด

## Hello world
Hello world แบบง่าย ๆ

```typescript
import { Elysia } from 'elysia'

new Elysia()
    .get('/', () => 'Hello World')
    .listen(3000)
```

## HTTP method แบบกำหนดเอง
สร้าง route ด้วย HTTP method/verb ที่กำหนดเอง

ดู [Route](/essential/route#custom-method)

```typescript
import { Elysia } from 'elysia'

new Elysia()
    .get('/hi', () => 'Hi')
    .post('/hi', () => 'From Post')
    .put('/hi', () => 'From Put')
    .method('M-SEARCH', '/hi', () => 'Custom Method')
    .listen(3000)
```

## Path parameter
ใช้ path parameter แบบ dynamic

ดู [Path](/essential/route/#path-types)

```typescript
import { Elysia } from 'elysia'

new Elysia()
    .get('/id/:id', ({ params: { id } }) => id)
    .get('/rest/*', () => 'Rest')
    .listen(3000)
```

## คืนค่าเป็น JSON
Elysia แปลง response เป็น JSON ให้อัตโนมัติ

ดู [Handler](/essential/handler)

```typescript
import { Elysia } from 'elysia'

new Elysia()
    .get('/json', () => {
        return {
            hello: 'Elysia'
        }
    })
    .listen(3000)
```

## คืนค่าเป็นไฟล์
return `file()` เพื่อส่งไฟล์เดียว และใช้ `form()` เพื่อส่งหลายไฟล์ใน response แบบ multipart form-data

form ต้องเป็น object ที่ลึกแค่ 1 ชั้น

ดู [Handler](/essential/handler/#return-a-file)

```typescript
import { Elysia, file, form } from 'elysia'

new Elysia()
    .get('/cat', file('public/cat.jpg'))
    .get('/form', () => {
        return form({
            hello: 'Elysia',
            image: file('public/cat.jpg')
        })
    })
    .listen(3000)
```

## Header และ status
ตั้งค่า header และ status code ตามต้องการ

ดู [Handler](/essential/handler)

```typescript
import { Elysia } from 'elysia'

new Elysia()
    .get('/', ({ set, status }) => {
        set.headers['x-powered-by'] = 'Elysia'

        return status(418, "I'm a teapot")
    })
    .listen(3000)
```

## Group
กำหนด prefix ครั้งเดียวให้ route ย่อยทั้งหมด

ดู [Group](/essential/route#group)

```typescript
import { Elysia } from 'elysia'

new Elysia()
    .get("/", () => "Hi")
    .group("/auth", app => {
        return app
            .get("/", () => "Hi")
            .post("/sign-in", ({ body }) => body)
            .put("/sign-up", ({ body }) => body)
    })
    .listen(3000)
```

## Schema
บังคับ type ของข้อมูลใน route

ดู [Validation](/essential/validation)

```typescript
import { Elysia, t } from 'elysia'

new Elysia()
    .post('/mirror', {
        body: t.Object({
            username: t.String(),
            password: t.String()
        })
    }, ({ body: { username } }) => username)
    .listen(3000)
```

## อัปโหลดไฟล์
ดู [Validation#file](/essential/validation/#file) ถ้าจะเช็ก `type` ต้องมีตัวตรวจจับชนิดไฟล์ด้วย: ติดตั้ง `file-type` แล้วลงทะเบียนด้วย `setFileTypeDetector` ไม่อย่างนั้นทุกไฟล์ที่อัปโหลดและเช็กด้วย `type` จะไม่ผ่าน validation

```typescript
import { Elysia, t, setFileTypeDetector } from 'elysia'
import { fileTypeFromBlob } from 'file-type'

setFileTypeDetector(fileTypeFromBlob)

new Elysia()
	.post('/body', {
		body: t.Object({
			file: t.File({ type: 'image/*' }),
			multipleFiles: t.Files()
		})
	}, ({ body }) => body)
	.listen(3000)
```

## Lifecycle hook
ดักจับ event ของ Elysia ตามลำดับ

ดู [Lifecycle](/essential/life-cycle)

```typescript
import { Elysia, t } from 'elysia'

new Elysia()
    .onRequest(() => {
        console.log('On request')
    })
    .onBeforeHandle(() => {
        console.log('Before handle')
    })
    .post('/mirror', {
        body: t.Object({
            username: t.String(),
            password: t.String()
        }),
        afterHandle: () => {
            console.log("After handle")
        }
    }, ({ body }) => body)
    .listen(3000)
```

## Guard
บังคับ type ของข้อมูลให้ route ย่อย

ดู [Guard](/essential/plugin/#guard)

```typescript
// @errors: 2345
import { Elysia, t } from 'elysia'

new Elysia()
    .guard({
        response: t.String()
    }, (app) => app
        .get('/', () => 'Hi')
        // Invalid: will throws error, and TypeScript will report error
        .get('/invalid', () => 1)
    )
    .listen(3000)
```

## Context แบบกำหนดเอง
เพิ่มตัวแปรของคุณเองลงใน context ของ route

ดู [Context](/essential/handler#context)

```typescript
import { Elysia } from 'elysia'

new Elysia()
    .state('version', 1)
    .decorate('getDate', () => Date.now())
    .get('/version', ({
        getDate,
        store: { version }
    }) => `${version} ${getDate()}`)
    .listen(3000)
```

## Redirect
ส่ง response แบบ redirect

import { Elysia } from 'elysia'

new Elysia()

## Plugin
สร้าง instance แยกออกมาต่างหาก

ดู [Plugin](/essential/plugin)

```typescript
import { Elysia } from 'elysia'

const plugin = new Elysia()
    .state('plugin-version', 1)
    .get('/hi', () => 'hi')

new Elysia()
    .use(plugin)
    .get('/version', ({ store }) => store['plugin-version'])
    .listen(3000)
```

## WebSocket
สร้างการเชื่อมต่อแบบ realtime ด้วย WebSocket

ดู [Web Socket](/patterns/websocket)

```typescript
import { Elysia } from 'elysia'
import { websocket } from 'elysia/websocket'

new Elysia()
    .use(websocket())
    .ws('/ping', {
        message(ws, message) {
            ws.send('hello ' + message)
        }
    })
    .listen(3000)
```

## เอกสาร OpenAPI
สร้างเอกสารแบบ interactive ด้วย Scalar (หรือจะใช้ Swagger ก็ได้)

ดู [openapi](/plugins/openapi)

```typescript
import { Elysia } from 'elysia'
import { openapi } from '@elysia/openapi'

const app = new Elysia()
    .use(openapi())
    .listen(3000)

console.log(`View documentation at "${app.server!.url}openapi" in your browser`);
```

## Unit test
เขียน unit test ให้แอป Elysia ของคุณ

ดู [Unit Test](/patterns/unit-test)

```typescript
// test/index.test.ts
import { describe, expect, it } from 'bun:test'
import { Elysia } from 'elysia'

describe('Elysia', () => {
    it('return a response', async () => {
        const app = new Elysia().get('/', () => 'hi')

        const response = await app
            .handle(new Request('http://localhost/'))
            .then((res) => res.text())

        expect(response).toBe('hi')
    })
})
```

## Body parser แบบกำหนดเอง
เขียน logic สำหรับ parse body ในแบบของคุณเอง

ดู [Parse](/essential/life-cycle#parse)

```typescript
import { Elysia } from 'elysia'

new Elysia()
    .onParse(({ request, contentType }) => {
        if (contentType === 'application/custom-type')
            return request.text()
    })
```

## GraphQL
สร้างเซิร์ฟเวอร์ GraphQL ของคุณเองด้วย GraphQL Yoga หรือ Apollo

ดู [GraphQL Yoga](/plugins/graphql-yoga)

```typescript
import { Elysia } from 'elysia'
import { yoga } from '@elysia/graphql-yoga'

const app = new Elysia()
    .use(
        yoga({
            typeDefs: /* GraphQL */`
                type Query {
                    hi: String
                }
            `,
            resolvers: {
                Query: {
                    hi: () => 'Hello from Elysia'
                }
            }
        })
    )
    .listen(3000)
```
