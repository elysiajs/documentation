<h1 id="_top">การใช้งานร่วมกับ AI SDK</h1>

Elysia รองรับ response streaming ได้สบายๆ ทำให้เราใช้งานร่วมกับ [Vercel AI SDKs](https://vercel.com/docs/ai) ได้อย่างลื่นไหล

## Response streaming

Elysia รองรับการ stream แบบต่อเนื่องของ `ReadableStream` และ `Response` ทำให้เราสามารถ return stream จาก AI SDK ได้โดยตรงเลย ในแต่ละตัวอย่างให้เราเลือกใช้ `return` แค่ statement เดียว

```ts
import { Elysia } from 'elysia'
import { streamText } from 'ai'
import { openai } from '@ai-sdk/openai'

new Elysia().get('/', () => {
    const stream = streamText({
        model: openai('gpt-5'),
        system: 'You are Yae Miko from Genshin Impact',
        prompt: 'Hi! How are you doing?'
    })

    // Just return a ReadableStream
    return stream.textStream

    // UI Message Stream is also supported
    return stream.toUIMessageStream()
})
```

Elysia จะช่วยจัดการ stream ให้อัตโนมัติ ทำให้เรานำไปใช้งานได้หลายรูปแบบ

## Server-sent events

Elysia รองรับ Server-Sent Events สำหรับ streaming response ด้วย แค่ครอบ `ReadableStream` ด้วยฟังก์ชั่น `sse`

```ts
import { Elysia, sse } from 'elysia'
import { streamText } from 'ai'
import { openai } from '@ai-sdk/openai'

new Elysia().get('/', () => {
    const stream = streamText({
        model: openai('gpt-5'),
        system: 'You are Yae Miko from Genshin Impact',
        prompt: 'Hi! How are you doing?'
    })

    // Each chunk will be sent as a Server Sent Event
    return sse(stream.textStream)

    // UI Message Stream is also supported
    return sse(stream.toUIMessageStream())
})
```

## ส่งกลับเป็น response

ถ้าเราไม่ต้องการนำ type safety จาก stream ไปใช้ต่อกับ [Eden](/eden) เราก็แค่ return stream ออกไปเป็น response ได้เลย

```ts
import { Elysia } from 'elysia'
import { streamText } from 'ai'
import { openai } from '@ai-sdk/openai'

new Elysia().get('/', () => {
    const stream = streamText({
        model: openai('gpt-5'),
        system: 'You are Yae Miko from Genshin Impact',
        prompt: 'Hi! How are you doing?'
    })

    return stream.toTextStreamResponse()

    // UI Message Stream Response will use SSE
    return stream.toUIMessageStreamResponse()
})
```

## stream ด้วยตัวเอง

ถ้าอยากควบคุมการ stream ได้มากขึ้น เราสามารถใช้ generator function เพื่อ yield แต่ละก้อนได้ด้วยตัวเอง

```ts
import { Elysia, sse } from 'elysia'
import { streamText } from 'ai'
import { openai } from '@ai-sdk/openai'

new Elysia().get('/', async function* () {
    const stream = streamText({
        model: openai('gpt-5'),
        system: 'You are Yae Miko from Genshin Impact',
        prompt: 'Hi! How are you doing?'
    })

    for await (const data of stream.textStream)
        yield sse({
            data,
            event: 'message'
        })

    yield sse({
        event: 'done'
    })
})
```

## Fetch

ถ้า AI SDK ไม่รองรับโมเดลที่กำลังใช้อยู่ เราก็ยังสามารถใช้ฟังก์ชั่น `fetch` ไปเรียก HTTP API ของ provider แล้ว stream response กลับไปได้ตรงๆ

```ts
import { Elysia } from 'elysia'

new Elysia().get('/', () => {
    return fetch('https://api.openai.com/v1/chat/completions', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            Authorization: `Bearer ${process.env.OPENAI_API_KEY}`
        },
        body: JSON.stringify({
            model: 'gpt-5',
            stream: true,
            messages: [
                {
                    role: 'system',
                    content: 'You are Yae Miko from Genshin Impact'
                },
                { role: 'user', content: 'Hi! How are you doing?' }
            ]
        })
    })
})
```

Elysia จะ proxy response จาก `fetch` ที่เป็น global พร้อมรองรับการ stream แบบอัตโนมัติ
