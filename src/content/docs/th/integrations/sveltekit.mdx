<h1 id="_top">ใช้งานร่วมกับ SvelteKit</h1>

ด้วย SvelteKit คุณรัน Elysia บน server routes ได้

1. สร้างไฟล์ **src/routes/[...slugs]/+server.ts**
2. ประกาศเซิร์ฟเวอร์ Elysia
3. export ฟังก์ชัน **fallback** ที่เรียก `app.handle`

```typescript
// src/routes/[...slugs]/+server.ts
import { Elysia, t } from 'elysia';

const app = new Elysia()
    .get('/', 'hello SvelteKit')
    .post('/', {
        body: t.Object({
            name: t.String()
        })
    }, ({ body }) => body)

interface WithRequest {
	request: Request
}

export const fallback = ({ request }: WithRequest) => app.handle(request)
```

คุณใช้เซิร์ฟเวอร์ Elysia ได้เหมือน server route ทั่วไปของ SvelteKit

### pnpm
ถ้าการตั้งค่า pnpm ของคุณไม่ได้ติดตั้ง peer dependency ให้ ให้เพิ่ม peer ที่ Elysia v2 ต้องใช้อย่างชัดเจน:
```bash
pnpm add typebox exact-mirror openapi-types
```

## Prefix
ถ้าคุณไม่ได้วางเซิร์ฟเวอร์ Elysia ไว้ที่รากของไดเรกทอรี routes ต้องระบุ prefix ให้เซิร์ฟเวอร์ Elysia

ตัวอย่างเช่น ถ้าวางเซิร์ฟเวอร์ Elysia ไว้ที่ **src/routes/api/[...slugs]/+server.ts** ต้องระบุ prefix เป็น **/api** ให้เซิร์ฟเวอร์ Elysia

```typescript
// src/routes/api/[...slugs]/+server.ts
import { Elysia, t } from 'elysia';

const app = new Elysia({ prefix: '/api' })
    .get('/', () => 'hi')
    .post('/', {
        body: t.Object({
            name: t.String()
        })
    }, ({ body }) => body)

type RequestHandler = (v: { request: Request }) => Response | Promise<Response>

export const fallback: RequestHandler = ({ request }) => app.handle(request)
```

วิธีนี้ทำให้ routing ของ Elysia ทำงานได้ถูกต้องไม่ว่าจะวางไว้ที่ไหน

ดูข้อมูลเพิ่มเติมได้ที่ [SvelteKit Routing](https://kit.svelte.dev/docs/routing#server)
