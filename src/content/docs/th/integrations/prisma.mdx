<h1 id="_top">Prisma</h1>

[Prisma](https://prisma.io) คือ ORM ที่ช่วยให้เราทำงานกับฐานข้อมูลได้แบบ type-safe

Prisma ช่วยให้เรากำหนด schema ของฐานข้อมูลไว้ในไฟล์ Prisma schema แล้วสร้าง TypeScript type ตาม schema ให้เลย

:::note[ความเข้ากันได้ของ generator]

ตั้งค่า Prismabox ให้ import `t` จาก `elysia` ตามตัวอย่างข้างล่าง แล้วเช็กว่าเวอร์ชันของ generator ที่ใช้รองรับ schema แบบ TypeBox 1.x ที่ Elysia v2 ใช้ โดยที่ Prisma กับ Prismabox นั้นเป็น integration ที่แยกส่วนกัน ตัวอย่างนี้จึงไม่ได้ยืนยันความเข้ากันได้ตอน runtime ของ Prisma กับ Prismabox ในทุกเวอร์ชัน

:::

### Prismabox
[Prismabox](https://github.com/m1212e/prismabox) เป็นไลบรารีที่สร้างโมเดล validation ของ TypeBox หรือ Elysia จาก Prisma schema

เราสามารถใช้ Prismabox เพื่อเปลี่ยน Prisma schema ให้เป็นโมเดล validation ของ Elysia เอาไปช่วยตรวจ type ใน Elysia ได้

### ทำงานยังไง
1. กำหนด schema ของฐานข้อมูลใน Prisma Schema
2. เพิ่ม `prismabox` generator เพื่อสร้าง Elysia schema
3. ใช้โมเดล validation ของ Elysia ที่แปลงมาแล้ว เพื่อตรวจสอบ type
4. Elysia สร้าง OpenAPI schema จากโมเดล validation ให้เอง
5. เพิ่ม [Eden Treaty](/eden) เพื่อเพิ่ม type-safety ให้ฝั่ง frontend

```text
                                                    * ——————————————— *
                                                    |                 |
                                               | -> |  Documentation  |
* ————————— *             * ———————— * OpenAPI |    |                 |
|           |  prismabox  |          | ——————— |    * ——————————————— *
|  Prisma   | —————————-> |  Elysia  |
|           |             |          | ——————— |    * ——————————————— *
* ————————— *             * ———————— *   Eden  |    |                 |
                                               | -> |  Frontend Code  |
												    |                 |
												    * ——————————————— *

```

## การติดตั้ง
รันคำสั่งนี้เพื่อติดตั้ง Prisma:

```bash
bun add @prisma/client prismabox prisma-adapter-bun-sqlite && \
bun add -d prisma
```

## Prisma schema
สมมุติว่าเรามีไฟล์ `prisma/schema.prisma` แล้ว

ในส่วน datasource ไม่มี `url` เพราะ Prisma 7 อ่าน URL ของฐานข้อมูลจาก `prisma.config.ts` ดูวิธีการตั้งค่า Prisma ได้จาก [เอกสารอ้างอิง](https://www.prisma.io/docs/orm/reference/prisma-config-reference)

เราสามารถเพิ่ม `prismabox` generator ไปที่ไฟล์ Prisma schema ตามตัวอย่างนี้:

```prisma title="prisma/schema.prisma"
generator client {
  provider = "prisma-client"
  output   = "../generated/prisma"
}

datasource db {
  provider = "sqlite"
  // Note: In Prisma 7+, datasource URL is configured in prisma.config.ts (for Prisma CLI),
  // and when using driver adapters you also pass the runtime URL in adapter setup.
}

generator prismabox {
  provider = "prismabox"
  typeboxImportDependencyName = "elysia"
  typeboxImportVariableName = "t"
  inputModel = true
  output   = "../generated/prismabox"
}

model User {
  id    String  @id @default(cuid())
  email String  @unique
  name  String?
  posts Post[]
}

model Post {
  id    	String  @id @default(cuid())
  title     String
  content   String?
  published Boolean @default(false)
  author    User    @relation(fields: [authorId], references: [id])
  authorId  String
}
```

Prismabox จะสร้างโมเดล validation ของ Elysia ไว้ในโฟลเดอร์ `generated/prismabox`

แต่ละโมเดลจะมีไฟล์ของตัวเอง และจะตั้งชื่อตามชื่อของโมเดล Prisma

ยกตัวอย่าง:
- โมเดล `User` จะถูกสร้างเป็นไฟล์ `generated/prismabox/User.ts`
- โมเดล `Post` จะถูกสร้างเป็นไฟล์ `generated/prismabox/Post.ts`

## ใช้งานโมเดลที่สร้าง
ตอนนี้เราสามารถ import โมเดลที่สร้างขึ้น มาใช้ในแอป Elysia ได้:


```ts title="src/index.ts"
import { Elysia, t } from 'elysia'

import { PrismaBunSqlite } from 'prisma-adapter-bun-sqlite';
import { PrismaClient } from '../generated/prisma/client'
import { UserPlain, UserPlainInputCreate } from '../generated/prismabox/User'

const adapter = new PrismaBunSqlite({ url: process.env.DATABASE_URL });
export const prisma = new PrismaClient({ adapter });

const app = new Elysia()
    .put(
        '/',
        {
            body: UserPlainInputCreate,
            response: UserPlain
        }, async ({ body }) =>
            prisma.user.create({
                data: body
            })
    )
    .get(
        '/id/:id',
        {
            response: {
                200: UserPlain,
                404: t.String()
            }
        }, async ({ params: { id }, status }) => {
            const user = await prisma.user.findUnique({
                where: { id }
            })

            if (!user) return status(404, 'User not found')

            return user
        }
    )
    .listen(3000)

console.log(
    `🦊 Elysia is running at ${app.server?.hostname}:${app.server?.port}`
)
```


เราก็จะใช้ schema ของฐานข้อมูลที่เขียนไว้ มาใช้ซ้ำเป็นโมเดล validation ของ Elysia ได้แล้ว
