<h1 id="_top">พารามิเตอร์</h1>

สุดท้ายแล้วเราก็ต้องส่ง payload ไปยังเซิร์ฟเวอร์

method ของ Eden Treaty จึงรับพารามิเตอร์ 2 ตัวสำหรับส่งข้อมูลไปยังเซิร์ฟเวอร์

พารามิเตอร์ทั้งสองเป็นแบบ type-safe และ TypeScript จะช่วยแนะนำให้อัตโนมัติ:

1. body
2. พารามิเตอร์เพิ่มเติม
    - query
    - headers
    - fetch

```ts
import { Elysia, t } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia()
    .post('/user', {
        body: t.Object({
            name: t.String()
        })
    }, ({ body }) => body)
    .listen(3000)

const api = treaty<typeof app>('localhost:3000')

// works
api.user.post({
    name: 'Elysia'
})

// also works
api.user.post({
    name: 'Elysia'
}, {
    // This is optional as not specified in schema
    headers: {
        authorization: 'Bearer 12345'
    },
    query: {
        id: 2
    }
})
```

ถ้า method เป็น **"GET"** หรือ **"HEAD"**:

1. พารามิเตอร์เพิ่มเติม
    -   query
    -   headers
    -   fetch

```ts
import { Elysia } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia()
    .get('/hello', () => 'hi')
    .listen(3000)

const api = treaty<typeof app>('localhost:3000')

// works
api.hello.get({
    // This is optional as not specified in schema
    headers: {
        hello: 'world'
    }
})
```

## Body ว่าง
ถ้า body เป็นแบบไม่บังคับหรือไม่จำเป็น แต่ต้องมี query หรือ header ให้ส่ง body เป็น `null` หรือ `undefined` แทน

```ts
import { Elysia, t } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia()
    .post('/user', {
        query: t.Object({
            name: t.String()
        })
    }, () => 'hi')
    .listen(3000)

const api = treaty<typeof app>('localhost:3000')

api.user.post(null, {
    query: {
        name: 'Ely'
    }
})
```

## พารามิเตอร์ของ fetch

Eden Treaty เป็น wrapper ของ fetch เราจึงเพิ่มพารามิเตอร์ของ [Fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) ที่ถูกต้องตัวใดก็ได้ให้ Eden ด้วยการส่งเข้าไปใน `fetch`:

```ts
import { Elysia, t } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia()
    .get('/hello', () => 'hi')
    .listen(3000)

const api = treaty<typeof app>('localhost:3000')

const controller = new AbortController()

const cancelRequest = setTimeout(() => {
    controller.abort()
}, 5000)

await api.hello.get({
    fetch: {
        signal: controller.signal
    }
})

clearTimeout(cancelRequest)
```

## อัปโหลดไฟล์
แนบไฟล์ได้ด้วยค่าต่อไปนี้:
- **File**
- **File[]**
- **FileList**
- **Blob**

การแนบไฟล์จะทำให้ **content-type** เป็น **multipart/form-data** ทั้งนี้ schema ของ route ยังเป็นตัวกำหนด type ของ TypeScript ที่ยอมรับ สำหรับ `t.Files()` ให้แปลง `FileList` จาก input เป็น `File[]` และใช้ `File` เมื่อ schema ต้องการไฟล์ ไม่ใช่ `Blob` ธรรมดา

สมมติว่าเรามีเซิร์ฟเวอร์ดังนี้:
```ts
// server.ts
import { Elysia, t } from 'elysia'

const app = new Elysia()
    .post('/image', {
        body: t.Object({
            title: t.String(),
            image: t.Files()
        })
    }, ({ body: { image, title } }) => title)
    .listen(3000)

export type App = typeof app
```

จากนั้นอัปโหลดจากฝั่ง client:
```ts
// client.ts
import { treaty } from '@elysia/eden'
import type { App } from './server'

const api = treaty<App>('localhost:3000')

const images = document.getElementById('images') as HTMLInputElement

const { data } = await api.image.post({
    title: "Misono Mika",
    image: Array.from(images.files ?? []),
})
```
