## อ่านข้อมูลจาก route

path จะกลายเป็น property บน client แล้วต่อท้ายด้วย HTTP method ของ path นั้น เช่น `api.hi.get()` จะเรียก `GET /hi` และได้ `Hi Elysia` กลับมา

ในตัวอย่างนี้เราส่ง instance เข้าไปตรง ๆ การเรียกจึงเกิดขึ้นใน process เดียวกัน ไม่ต้องมีเซิร์ฟเวอร์ที่เปิด listen รออยู่

</InteractiveStep>

## ส่ง path parameter

เรียก segment แบบ dynamic ด้วย object ที่มีชื่อ parameter ของมัน เช่น `api.id({ id: 1895 }).get()` จะเรียก `GET /id/1895`

TypeScript รู้ว่า route นี้รับ parameter อะไรบ้าง

## ส่ง body

ส่ง body ให้ method อย่าง `post` แล้ว schema ของ route จะคอยบอก client ว่าต้องส่งอะไร: request นี้ต้องมี `id` ที่เป็นตัวเลข และ `name` ที่เป็น string

เซิร์ฟเวอร์จะส่ง object เดิมกลับมา อย่าลืมเช็ก `error` ก่อนใช้ `data`

ถ้าจะเรียกเซิร์ฟเวอร์ที่รันแยกอยู่ ให้ export type ของเซิร์ฟเวอร์ Elysia ที่มีอยู่ก่อน:

```ts
// server.ts
import { Elysia, t } from 'elysia'

const app = new Elysia()
    .get('/hi', () => 'Hi Elysia')
    .get('/id/:id', ({ params: { id } }) => id)
    .post('/mirror', {
        body: t.Object({
            id: t.Number(),
            name: t.String()
        })
    }, ({ body }) => body)
    .listen(3000)

export type App = typeof app
```

จากนั้น import type ของเซิร์ฟเวอร์ แล้วเรียกใช้ Elysia API จากฝั่ง client:

**client.ts**

```ts
// client.ts
import { treaty } from '@elysia/eden'
import type { App } from './server'

const app = treaty<App>('localhost:3000')

// response type: 'Hi Elysia'
const { data, error } = await app.hi.get()
```

## Syntax แบบโครงสร้างต้นไม้

HTTP path คือตัวระบุ resource ในโครงสร้างต้นไม้แบบระบบไฟล์

ระบบไฟล์ประกอบด้วยโฟลเดอร์ที่ซ้อนกันหลายชั้น เช่น:

-   /documents/elysia
-   /documents/kalpas
-   /documents/kelvin

แต่ละชั้นคั่นด้วย **/** (slash) ตามด้วยชื่อ

แต่ใน JavaScript เราใช้ **"."** (dot) แทน **"/"** (slash) เพื่อเข้าถึง resource ที่อยู่ลึกลงไป

Eden Treaty จะเปลี่ยนเซิร์ฟเวอร์ Elysia ให้เป็นโครงสร้างต้นไม้คล้ายระบบไฟล์ ที่เข้าถึงได้จากฝั่ง frontend ด้วย JavaScript แทน

| Path         | Treaty       |
| ------------ | ------------ |
| /            |              |
| /hi          | .hi          |
| /deep/nested | .deep.nested |

เมื่อรวมกับ HTTP method เราก็ติดต่อกับเซิร์ฟเวอร์ Elysia ได้แล้ว

| Path         | Method | Treaty              |
| ------------ | ------ | ------------------- |
| /            | GET    | .get()              |
| /hi          | GET    | .hi.get()           |
| /deep/nested | GET    | .deep.nested.get()  |
| /deep/nested | POST   | .deep.nested.post() |

## Path แบบ dynamic

path parameter แบบ dynamic ต้องมีทั้งชื่อและค่า สำหรับ client `api` ที่เซิร์ฟเวอร์ลงทะเบียน `/item/:name` ไว้ ให้เรียกเป็นฟังก์ชันเพื่อระบุ parameter

```ts
// Unclear what the value is supposed to represent?
api.item['skadi'].get()
```

การเข้าถึงผ่าน property แบบนี้เป็นของ client [Eden Treaty 1 รุ่นเก่า](/eden/treaty/legacy) ส่วนใน Eden Treaty 2 จะเป็น type error

เพื่อแก้ปัญหานี้ เราระบุ dynamic path ด้วยฟังก์ชันที่ส่ง key และ value เข้าไปแทนได้

```ts
// Clear that the value is dynamic and the path is 'name'
api.item({ name: 'Skadi' }).get()
```

| Path            | Treaty                           |
| --------------- | -------------------------------- |
| /item           | .item                            |
| /item/:name | `.item({ name: 'Skadi' })` |
| /item/:name/id | `.item({ name: 'Skadi' }).id` |
