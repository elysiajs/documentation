<h1 id="_top">Unit test</h1>

ตาม[การตั้งค่า Eden Treaty](/eden/treaty/config#urlorinstance) และ [Unit Test](/patterns/unit-test) เราส่ง instance ของ Elysia ให้ Eden Treaty โดยตรงได้ เพื่อเรียกใช้เซิร์ฟเวอร์ Elysia โดยไม่ต้องส่ง request ผ่านเครือข่าย

เราใช้รูปแบบนี้เขียน unit test ที่มีทั้ง type safety แบบ end-to-end และการทดสอบระดับ type ไปพร้อมกันได้

```ts
// test/index.test.ts
import { describe, expect, it } from 'bun:test'
import { Elysia } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia().get('/hello', 'hi')
const api = treaty(app)

describe('Elysia', () => {
    it('returns a response', async () => {
        const { data } = await api.hello.get()

        expect(data).toBe('hi')

    })
})
```

## ทดสอบ type safety
ใส่โฟลเดอร์เทสต์ของคุณไว้ใน `tsconfig.json` แล้วรัน TypeScript ด้วย compiler option ของโปรเจกต์

```bash
bunx tsc --noEmit
```

วิธีนี้ช่วยรับประกันความถูกต้องของ type ทั้งฝั่ง client และเซิร์ฟเวอร์ โดยเฉพาะระหว่างการ migrate
