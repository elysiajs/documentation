<h1 id="_top">Eden Fetch</h1>

ทางเลือกแบบ fetch นอกเหนือจาก Eden Treaty

Eden Fetch ช่วยให้คุณเรียกใช้เซิร์ฟเวอร์ Elysia แบบ type-safe ผ่าน Fetch API

---

เริ่มจาก export type ของเซิร์ฟเวอร์ Elysia ที่มีอยู่:
```ts
// server.ts
import { Elysia, t } from 'elysia'

const app = new Elysia()
    .get('/hi', () => 'Hi Elysia')
    .get('/id/:id', ({ params: { id } }) => id)
    .post('/mirror', {
        body: t.Object({
            id: t.Number(),
            name: t.String()
        })
    }, ({ body }) => body)
    .listen(3000)

export type App = typeof app
```

จากนั้น import type ของเซิร์ฟเวอร์ แล้วเรียกใช้ API ของ Elysia ฝั่ง client:
```ts
import { edenFetch } from '@elysia/eden'
import type { App } from './server'

const fetch = edenFetch<App>('http://localhost:3000')

// response type: 'Hi Elysia'
const { data: pong } = await fetch('/hi', {})

// response type: 1895
const { data: id } = await fetch('/id/:id', {
    params: {
        id: '1895'
    }
})

// response type: { id: 1895, name: 'Skadi' }
const { data: nendoroid } = await fetch('/mirror', {
    method: 'POST',
    body: {
        id: 1895,
        name: 'Skadi'
    }
})
```

## การจัดการ error
คุณจัดการ error ได้แบบเดียวกับ Eden Treaty:
```ts
import { edenFetch } from '@elysia/eden'
import type { App } from './server'

const fetch = edenFetch<App>('http://localhost:3000')

// response type: { id: 1895, name: 'Skadi' }
const { data: nendoroid, error } = await fetch('/mirror', {
    method: 'POST',
    body: {
        id: 1895,
        name: 'Skadi'
    }
})

if(error) {
    switch(error.status) {
        case 400:
        case 401:
            throw error.value
            break

        case 500:
        case 502:
            throw error.value
            break

        default:
            throw error.value
            break
    }
}

const { id, name } = nendoroid
```

## เมื่อไรควรใช้ Eden Fetch แทน Eden Treaty
เลือกรูปแบบการเรียก request ที่เหมาะกับโปรเจกต์ของคุณ ไม่มี client ตัวไหนตรวจสอบ type ได้เร็วกว่าในทุกกรณี

การเลือกขึ้นอยู่กับข้อตกลงในทีมของคุณ แต่เราแนะนำให้ใช้ [Eden Treaty](/eden/treaty/overview)

สำหรับ API ขนาดใหญ่ เช่น frontend หนึ่งตัวที่เรียกใช้**มากกว่า 500 route** ให้ลองเปรียบเทียบการตรวจสอบของ TypeScript และความลื่นของ editor ในโปรเจกต์ของคุณเอง Eden Fetch อาจคุ้มที่จะลองเมื่อการอนุมานของ Treaty เริ่มกินทรัพยากร แต่จำนวน route อย่างเดียวไม่ได้รับประกันประสิทธิภาพ
