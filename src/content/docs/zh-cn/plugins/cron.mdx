<h1 id="_top">Cron 插件</h1>

此插件支持在 Elysia 服务器中运行 Cron 定时任务。

安装：

```bash
bun add @elysia/cron@rc
```

然后这样使用：

```ts
import { Elysia } from 'elysia'
import { cron } from '@elysia/cron'

new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: '*/10 * * * * *',
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.listen(3000)
```

此代码每 10 秒记录一次 `Heartbeat`。

## cron

为 Elysia 服务器创建 Cron 定时任务。

类型：

```text
cron(config: CronConfig): (app: Elysia) => Elysia
```

`CronConfig` 接受以下参数：

### name

要注册到 `store` 的任务名称。

这会将 Cron 实例以指定名称注册到 `store`，供后续操作引用，例如停止任务。

### pattern

按照下方的 [Cron 语法](https://en.wikipedia.org/wiki/Cron)指定任务的运行时间：

```text
┌────────────── second (optional)
│ ┌──────────── minute
│ │ ┌────────── hour
│ │ │ ┌──────── day of the month
│ │ │ │ ┌────── month
│ │ │ │ │ ┌──── day of week
│ │ │ │ │ │
* * * * * *
```

可以使用 [Crontab Guru](https://crontab.guru/) 等工具生成表达式。

### run

每次任务触发时要执行的函数。

---

此插件使用 [Croner](https://github.com/hexagon/croner) 注册定时任务。

以下是支持的 Croner 选项。

### timezone

时区，格式如 Europe/Stockholm

### startAt

任务计划的开始时间

### stopAt

任务计划的结束时间

### maxRuns

最大执行次数

### catch

即使触发的函数抛出未处理错误，也继续执行。

### interval

两次执行之间的最短间隔，单位为秒。

## 用法模式

以下是此插件的常见用法。

## 停止 Cron 任务

你可以通过访问注册在 `store` 中的 Cron 任务名称来手动停止任务。

```ts
import { Elysia } from 'elysia'
import { cron } from '@elysia/cron'

const app = new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: '*/1 * * * * *',
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.get(
		'/stop',
		({
			store: {
				cron: { heartbeat }
			}
		}) => {
			heartbeat.stop()

			return 'Stop heartbeat'
		}
	)
	.listen(3000)
```

## 预定义模式

你可以从 `@elysia/cron` 导入 `Patterns`。

```ts
import { Elysia } from 'elysia'
import { cron, Patterns } from '@elysia/cron'

const app = new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: Patterns.everySecond(),
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.get(
		'/stop',
		({
			store: {
				cron: { heartbeat }
			}
		}) => {
			heartbeat.stop()

			return 'Stop heartbeat'
		}
	)
	.listen(3000)
```

### 函数

| 函数                                     | 说明                                                  |
| ---------------------------------------- | ----------------------------------------------------- |
| `.everySeconds(2)`                       | 每 2 秒运行一次任务                                     |
| `.everyMinutes(5)`                       | 每 5 分钟运行一次任务                                   |
| `.everyHours(3)`                         | 每 3 小时运行一次任务                                   |
| `.everyHoursAt(3, 15)`                   | 每 3 小时的第 15 分钟运行一次任务                       |
| `.everyDayAt('04:19')`                   | 每天 04:19 运行任务                                     |
| `.everyWeekOn(Patterns.MONDAY, '19:30')` | 每周一 19:30 运行任务                                   |
| `.everyWeekdayAt('17:00')`               | 周一至周五每天 17:00 运行任务                           |
| `.everyWeekendAt('11:00')`               | 周六和周日 11:00 运行任务                               |

### 函数对应的常量别名

| 函数              | 常量                               |
