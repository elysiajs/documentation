<h1 id="_top">插件概览</h1>

Elysia 的设计注重模块化与轻量化。

这与 Arch Linux 的理念相同（顺便说一句，我用 Arch）：

> 设计决策由开发者针对具体情况协商确定

这样开发者就能按自己的需要构建高性能 Web 服务器。因此，Elysia 也提供了一些常见模式的预构建插件，方便使用：

:::note[插件版本]

请使用 Elysia peer 依赖与应用版本匹配的插件。Elysia 2 插件分支使用预发布版本；较早的插件版本可能依赖已移除的 Elysia 1 API。下方的社区插件列表仅供查找，不保证兼容性。

:::

## 社区插件

-   [Create ElysiaJS](https://github.com/kravetsone/create-elysiajs) - 轻松搭建 Elysia 项目环境（支持 ORM、代码检查工具和插件）！
-   [Lucia Auth](https://github.com/pilcrowOnPaper/lucia) - 简洁清晰的身份验证
-   [Elysia Clerk](https://github.com/wobsoriano/elysia-clerk) - 非官方 Clerk 身份验证插件
-   [Elysia Polyfills](https://github.com/bogeychan/elysia-polyfills) - 在 Node.js 和 Deno 上运行 Elysia 生态
-   [Vite server](https://github.com/kravetsone/elysia-vite-server) - 在 `development` 和 `production` 模式下启动并扩展 [`vite`](https://vitejs.dev/) 开发服务器，也可按需提供静态文件
-   [Vite](https://github.com/timnghg/elysia-vite) - 注入 Vite 脚本并提供入口 HTML 文件
-   [Nuxt](https://github.com/trylovetom/elysiajs-nuxt) - 轻松将 Elysia 集成到 Nuxt！
-   [Remix](https://github.com/kravetsone/elysia-remix) - 使用支持 `HMR` 的 [Remix](https://remix.run/)（由 [`vite`](https://vitejs.dev/) 提供支持）！实现了期待已久的插件请求 [#12](https://github.com/elysiajs/elysia/issues/12)
-   [Sync](https://github.com/johnny-woodtke/elysiajs-sync) - 基于 [Dexie.js](https://dexie.org/) 的轻量级离线优先数据同步框架
-   [Connect middleware](https://github.com/kravetsone/elysia-connect-middleware) - 允许在 Elysia 中直接使用 [`express`](https://www.npmjs.com/package/express)/[`connect`](https://www.npmjs.com/package/connect) 中间件的插件！
-   [Elysia HTTP Exception](https://github.com/codev911/elysia-http-exception) - 使用结构化异常类处理 HTTP 4xx/5xx 错误的 Elysia 插件
-   [Elysia Helmet](https://github.com/DevTobias/elysia-helmet) - 使用各种 HTTP 响应头增强 Elysia 应用的安全性
-   [Vite Plugin SSR](https://github.com/timnghg/elysia-vite-plugin-ssr) - 使用 Elysia 服务器的 Vite SSR 插件
-   [OAuth 2.0](https://github.com/kravetsone/elysia-oauth2) - 支持超过 **42** 个提供方并提供**类型安全**的 [OAuth 2.0](https://en.wikipedia.org/wiki/OAuth) 授权流程插件！
-   [OAuth2](https://github.com/bogeychan/elysia-oauth2) - 处理 OAuth 2.0 授权码流程
-   [OAuth2 Resource Server](https://github.com/ap-1/elysia-oauth2-resource-server) - 根据 JWKS 端点验证 OAuth2 提供方 JWT 令牌的插件，支持校验签发者、受众和范围
-   [Elysia OpenID Client](https://github.com/macropygia/elysia-openid-client) - 基于 [openid-client](https://github.com/panva/node-openid-client) 的 OpenID 客户端
-   [Rate Limit](https://github.com/rayriffy/elysia-rate-limit) - 简单轻量的速率限制器
-   [Elysia Nazli](https://github.com/esbuker/elysia-nazli) - 使用方便、支持可插拔存储的速率限制器，可配置全局和逐路由规则。
-   [LLMs.txt](https://github.com/opuu/elysia-llms-txt) - 根据 OpenAPI/Swagger 生成 `/llms.txt`，让文档更适合 LLM 使用
-   [Logysia](https://github.com/tristanisham/logysia) - 经典的日志中间件
-   [Logestic](https://github.com/cybercoder-naj/logestic) - 面向 ElysiaJS 的高级可定制日志库
-   [Logger](https://github.com/bogeychan/elysia-logger) - 基于 [pino](https://github.com/pinojs/pino) 的日志中间件
-   [Elysia Line](https://github.com/KrataiB/elysia-line) - 将 LINE Messaging API 和 LINE Login 集成到 Elysia 中（封装官方 [@line/bot-sdk](https://github.com/line/line-bot-sdk-nodejs)）
-   [Elylog](https://github.com/eajr/elylog) - 简单且可进行一定程度自定义的 stdout 日志库
-   [Logify for Elysia.js](https://github.com/0xrasla/logify) - 面向 Elysia.js 应用的美观、高速且类型安全的日志中间件
-   [Nice Logger](https://github.com/tanishqmanuja/nice-logger) - 不敢说最出色，但确实相当不错又轻巧的 Elysia 日志工具
-   [LogTape for Elysia](https://logtape.org/manual/integrations#elysia) - 通过 [LogTape](https://logtape.org/) 支持多个输出目标（传输器）的结构化日志中间件
-   [Sentry](https://github.com/johnny-woodtke/elysiajs-sentry) - 使用此 [Sentry](https://docs.sentry.io/) 插件捕获追踪数据和错误
-   [Apitally](https://github.com/apitally/apitally-js) - 在 [Apitally](https://apitally.io/elysia) 中收集指标、日志和追踪数据；这是一个简单的 API 监控与分析工具
-   [Elysia Lambda](https://github.com/TotalTechGeek/elysia-lambda) - 部署到 AWS Lambda
-   [Decorators](https://github.com/gaurishhs/elysia-decorators) - 使用 TypeScript 装饰器
-   [Elysia FSR](https://github.com/deadlinecode/elysia-fsr) - 文件系统路由，支持与 Eden 兼容的类型生成、monorepo/workspace，以及逻辑路由分组
-   [Autoload](https://github.com/kravetsone/elysia-autoload) - 基于目录结构的文件系统路由器，可为 [Eden](/eden) 生成类型，并支持 [`Bun.build`](https://github.com/kravetsone/elysia-autoload?tab=readme-ov-file#bun-build-usage)
-   [Msgpack](https://github.com/kravetsone/elysia-msgpack) - 支持使用 [MessagePack](https://msgpack.org)
-   [XML](https://github.com/kravetsone/elysia-xml) - 支持处理 XML
-   [Autoroutes](https://github.com/wobsoriano/elysia-autoroutes) - 文件系统路由
-   [Group Router](https://github.com/itsyoboieltr/elysia-group-router) - 基于文件系统和目录的分组路由器
-   [Basic Auth](https://github.com/itsyoboieltr/elysia-basic-auth) - 基本 HTTP 身份验证
-   [Body Limit](https://github.com/hexadecimal233/elysia-body-limit) - 限制 Elysia 中的请求体大小
-   [ETag](https://github.com/bogeychan/elysia-etag) - 自动生成 HTTP [ETag](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/ETag)
