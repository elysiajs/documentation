<h1 id="_top">Bun 全栈开发服务器</h1>

Bun 的[全栈开发服务器](https://bun.com/docs/bundler/fullstack)会打包前端资源，并支持热模块替换（HMR）。本指南使用 Bun 1.3 或更高版本以及 Elysia v2 静态插件。

这样就能直接使用 React，无需 Vite 或 Webpack 等打包工具。

## 设置服务器

安装 Elysia v2 静态插件：

```bash
bun add elysia@rc @elysia/static@next react react-dom
bun add -d @types/react @types/react-dom
```

:::tip

启动服务器前，设置 `bunFullstack: true` 并等待 `staticPlugin()` 完成。插件默认只提供普通静态文件服务；仅等待插件完成并不会启用 HTML 打包器。

:::

## 自定义前缀路径

向 `staticPlugin` 传入 `prefix` 选项，即可更改默认的 `/public` 前缀。

这样静态文件就会从 `/` 而不是 `/public` 提供。

更多配置选项请参阅[静态插件](/plugins/static/)。

## 构建生产版本

你可以像构建普通 Elysia 服务器一样构建全栈服务器。

```bash
bun build --compile --target bun --outfile server src/index.ts
```

这会生成名为 `server` 的可执行文件。请同时测试生产构建和开发环境中的 HMR。

运行 **server** 可执行文件时，确保像开发环境一样一并提供 **public** 文件夹。

更多信息请参阅[部署到生产环境](/patterns/deploy)。
