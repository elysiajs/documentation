<h1 id="_top">Eden 插件</h1>

Eden 插件为 Eden Treaty 客户端添加自定义方法和变更钩子。

插件 API 在 Eden v2 beta 中可用。请按照 [Eden 安装说明](/eden/installation/)安装匹配版本的 Eden 和 Elysia。

## 添加自定义方法

`createPlugin` 会推断每个动词的调用签名，并将其添加到每条路由。上下文参数包含 `path`、`paths`、`domain` 和 `config`。如果传入 Elysia 实例，上下文还会包含 `elysia`。

### 使用 `PluginTypeFn` 控制方法类型

定义一个 `PluginTypeFn`，并将其用作 `TreatyPlugin` 的类型参数，即可只为匹配的路由添加方法。类型决定方法是否可用；`verbs` 则在运行时实现该方法。以下示例为标记了 `live: true` 的 GET 路由添加 `routePath`：

```ts
import { Elysia } from 'elysia'
import { treaty } from '@elysia/eden'
import type { PluginTypeFn, TreatyPlugin } from '@elysia/eden'

const app = new Elysia()
	.macro({ live: { meta: { live: true } as const } })
	.get('/users/:id', { live: true }, ({ params }) => params.id)
	.get('/health', () => 'ok')

interface RouteInfoTypeFn extends PluginTypeFn {
	output: this['node'] extends { get: { meta: { live: true } } }
		? { routePath: () => string }
		: {}
}

const routeInfo: TreatyPlugin<RouteInfoTypeFn> = {
	name: 'route-info',
	verbs: {
		routePath(context) {
			return context.path
		}
	}
}

const api = treaty(app).use(routeInfo)

api.users({ id: 1 }).routePath() // '/users/1'
api.health.get()
// @ts-expect-error This route is not marked live.
api.health.routePath()
```

请保留 `.use(plugin)` 返回的客户端，原始客户端不包含该插件。自定义方法会运行插件代码，不会发送 HTTP 请求。

## 观察变更

`before` 会在变更请求发出前运行。`after` 接收请求结果和相同的调用上下文。

```ts
import { Elysia, t } from 'elysia'
import { createPlugin, treaty } from '@elysia/eden'

const app = new Elysia()
	.post('/message', {
		body: t.Object({ text: t.String() })
	}, ({ body }) => body)

const logger = createPlugin({
	name: 'mutation-logger',
	before(context) {
		console.log('Sending', context.method, context.paths)
	},
	after(result, context) {
		console.log('Received', context.method, result.status)
	}
})

const api = treaty(app).use(logger)

await api.message.post({ text: 'Hello' })
// Sending post [ 'message' ]
// Received post 200
```

这些钩子会在 `post`、`put`、`patch` 和 `delete` 请求中运行，不适用于读取请求、WebSocket 订阅或自定义方法。调用上下文包含 `paths`、小写形式的 `method`、请求 `options`、`config` 和 `domain`。结果包含 `data`、`error`、`status`、`response` 和 `headers`；如果请求未到达服务器，最后两项可能是 `undefined`。

## 注册规则

插件必须提供非空的 `name`，以及 `verbs` 对象、`before` 或 `after` 之一。

插件方法不能替代 Treaty 的 HTTP 方法、`subscribe`、`use`、`~path`、`then`、`catch` 或 `finally`。如果注册了保留名称，或注册了其他插件已注册的方法，就会抛出错误。

通过链式调用 `.use` 组合插件。变更钩子按注册顺序运行。

Eden 的 `.use` 用于扩展客户端。若要为服务器添加路由或钩子，请改用 [Elysia 插件](/essential/plugin/)。
