<h1 id="_top">路由</h1>

[REST API](https://en.wikipedia.org/wiki/REST) 会根据路径和请求方法决定运行哪个处理器。

<CodePlayground elysia={demo1}>

```ts
import { Elysia } from 'elysia'

new Elysia()
    .get('/', 'Elysia')
    .get('/hi', 'Hello!')
    .listen(3000)
```

</CodePlayground>

> 调用 `.listen` 会在 3000 端口启动 Web 服务器。

访问 http://localhost:3000 即可连接服务器。

- 使用 `GET` 方法访问 `/` 会返回 `Elysia`
- 使用 `GET` 方法访问 `/hi` 会返回 `Hello!`
- 其他路径都会返回 `404`

在浏览器中访问 URL 时，会发送 `GET` 请求。

## 静态路径

静态路径会精确匹配，不会有意外。

- `/` 仅匹配 `/`
- `/hi` 仅匹配 `/hi`

</InteractiveStep>

<InteractiveStep>

## 动态路径

在 `:` 后添加名称，即可捕获对应的值。

`/user/:id` 可匹配 `/user/42`、`/user/abc` 和 `/user/hello-world`

</InteractiveStep>

<InteractiveStep>

### 读取参数

在处理器中从 `params` 读取匹配到的值。

当 `/user/42/profile` 匹配 `/user/:id/profile` 时，`params.id` 的值为 `42`。处理器会将它作为响应返回。

</InteractiveStep>

<InteractiveStep>

### 可选参数

在参数名后添加 `?`，即可将其设为可选参数。

`/user/:id?/profile` 既可匹配 `/user/42/profile`，也可匹配 `/user/profile`

如果请求中没有该参数，它的值就是 `undefined`。

</InteractiveStep>

<InteractiveStep>

## 通配符

在路径末尾添加 `*`，即可匹配后续的任意路径。

`/user/*` 可以匹配多段路径，例如 `/user/hello-world/profile`。在此示例中，`/user/42` 仍会匹配 `/user/:id`，因为动态路径的优先级高于通配符（参见[路径优先级](#path-priority)）。

对于 `/user/hello-world/profile`，`params['*']` 的值为 `hello-world/profile`。

</InteractiveStep>

</InteractiveDoc>

## HTTP 方法

[HTTP 方法](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Methods)是请求使用的方法，例如 `GET`、`POST` 或 `PUT`。

要定义标准方法，请在 Elysia 实例上使用对应的方法：

```ts
import { Elysia } from 'elysia'

new Elysia()
	.get('/', 'Hi GET!')
	.post('/', 'Hi POST!')
	.put('/', 'Hi PUT!')
	.patch('/', 'Hi PATCH!')
	.delete('/', 'Hi DELETE!')
	.listen(3000)
```

<a id="custom-method" />
### 自定义方法

使用 `.method` 定义，并将方法名作为第一个参数。其余参数与其他方法相同。

```ts
import { Elysia } from 'elysia'

new Elysia()
	.method('PROPFIND', '/', 'Hi PROPFIND!')
	.listen(3000)
```

### 所有方法

使用 `.all` 捕获所有方法：

```ts
import { Elysia } from 'elysia'

new Elysia()
	.all('/', 'Hi ALL!')
	.listen(3000)
```

<a id="group" />
## 分组

可以使用 `.group` 将多个具有相同前缀的路径分组：

<CodePlayground elysia={demo3}>

```ts
import { Elysia } from 'elysia'

new Elysia()
    .group('/user', (app) =>
        app
            .post('/sign-in', 'Sign in')
            .get('/profile', 'Profile')
    )
    .listen(3000)
```

</CodePlayground>

这相当于分别编写 `/user/sign-in` 和 `/user/profile`。

### 前缀

如果整个实例都使用相同的前缀，可以在构造函数中定义：

<CodePlayground elysia={demo4}>

```ts
import { Elysia } from 'elysia'

new Elysia({ prefix: '/user' })
    .post('/sign-in', 'Sign in')
    .get('/profile', 'Profile')
```

</CodePlayground>

这与 `.group` 不同：此前缀会应用于实例中的所有路径，而分组只应用于回调函数中的路径。
