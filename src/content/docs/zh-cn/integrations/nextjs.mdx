<h1 id="_top">集成 Next.js</h1>

使用 Next.js App Router，可以在 Next.js 路由中运行 Elysia。

1. 创建 **app/api/[[...slugs]]/route.ts**
2. 定义 Elysia 服务
3. 使用你需要的 HTTP 方法名称导出 **Elysia.fetch**


```typescript title="app/api/[[...slugs]]/route.ts"
import { Elysia, t } from 'elysia'

const app = new Elysia({ prefix: '/api' })
    .get('/', 'Hello Nextjs')
    .post('/', {
        body: t.Object({
            name: t.String()
        })
    }, ({ body }) => body)

export const GET = app.fetch
export const POST = app.fetch
```


得益于对 WinterTC 的兼容，Elysia 可以正常工作。

你可以像使用普通 Next.js API 路由一样使用 Elysia 服务。

采用这种方式，前后端可以共置于同一个仓库，并在客户端代码和服务端操作（Server Actions）中使用 [Eden 实现端到端类型安全](/eden)。

### pnpm
如果 pnpm 配置不会安装 peer 依赖，请显式添加 Elysia v2 所需的依赖：
```bash
pnpm add typebox exact-mirror openapi-types
```

## 前缀

由于 Elysia 服务不在 App Router 的根目录下，你需要在 Elysia 服务上设置前缀。

例如，如果将 Elysia 服务放在 **app/user/[[...slugs]]/route.ts**，就需要在 Elysia 服务上将前缀设为 **/user**。


```typescript title="app/user/[[...slugs]]/route.ts"
import { Elysia, t } from 'elysia'

const app = new Elysia({ prefix: '/user' })
	.get('/', 'Hello Nextjs')
    .post('/', {
        body: t.Object({
            name: t.String()
        })
    }, ({ body }) => body)

export const GET = app.fetch
export const POST = app.fetch
```


这样无论将 Elysia 放在哪里，路由都能正常工作。

## Eden

你可以添加 [Eden](/eden)，获得类似 tRPC 的**端到端类型安全**。

这种方式会使用同构 fetch 模式，让 Elysia 能够：
1. 在服务端：直接调用 Elysia，不经过网络层
2. 在客户端：通过网络层调用 Elysia

首先，按以下步骤操作：

1. 导出 Elysia 实例


```typescript title="lib/server.ts"
import { Elysia, t } from 'elysia'

export const app = new Elysia({ prefix: '/api' })
	.get('/', 'Hello Nextjs')
	.post(
		'/user',
		{
			body: t.Object({
				name: t.String()
			})
		}, ({ body }) => body
	)

```

路由文件中只保留 Next.js 路由导出：

```typescript title="app/api/[[...slugs]]/route.ts"
import { app } from '../../../lib/server'

export const GET = app.fetch
export const POST = app.fetch
```


2. 分别创建服务端和浏览器客户端

服务端使用的客户端可以直接调用 Elysia 实例。请确保它的运行时导入不会进入浏览器包：

```typescript title="lib/eden.server.ts"
import 'server-only'
import { treaty } from '@elysia/eden'
import { app } from './server'

export const api = treaty(app).api
```

浏览器客户端只导入 app 的类型，并发起 HTTP 请求：

```typescript title="lib/eden.ts"
import { treaty } from '@elysia/eden'
import type { app } from './server'

export const api = treaty<typeof app>('http://localhost:3000').api
```

生产环境请使用部署后的源站地址。这样服务端与客户端的边界更加明确，也不依赖打包后的 `process` 全局变量。

3. 在服务端和客户端组件中使用客户端


```tsx title="app/page.tsx"
import { api } from '../lib/eden.server'

export default async function Page() {
	const { data: message } = await api.get()

	return <h1>Hello, {message}</h1>
}
```


只需少量配置，就能获得从前端到后端的类型安全，服务端和客户端组件以及增量静态再生成（ISR）都适用。

## React Query
你也可以在客户端使用 React Query 与 Elysia 服务交互。


```tsx title="app/client.tsx"
'use client'

import { useQuery } from '@tanstack/react-query'
import { api } from '../lib/eden'

export default function App() {
	const { data: response } = useQuery({
		queryKey: ['get'],
		queryFn: () => api.get()
	})

	return response?.data
}
```


将此客户端组件放在 `QueryClientProvider` 下。你可以使用 React Query 的缓存、分页和无限查询等功能。
