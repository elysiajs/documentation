# TypeScript

Elysia viene con soporte de primer nivel para TypeScript, listo para usar.

Casi nunca vas a necesitar agregar anotaciones de TypeScript a mano.

## Inferencia
Elysia infiere el tipo de la request y de la respuesta a partir del schema que le des.

```ts twoslash
import { Elysia, t } from 'elysia'
import { z } from 'zod'

const app = new Elysia()
  	.post('/user/:id', ({ body }) => body, {
  	//                     ^?
	  	body: t.Object({
			id: t.String()
		}),
		query: z.object({
			name: z.string()
		})
   	})
```

Elysia puede inferir tipos automáticamente desde schemas como TypeBox y [tu librería de validación favorita](/essential/validation#standard-schema), por ejemplo:
- Zod
- Valibot
- ArkType
- Effect Schema
- Yup
- Joi

### Del schema al tipo

Todas las librerías de schemas que soporta Elysia se pueden convertir a tipos de TypeScript.

## Rendimiento de tipos

Elysia está construido pensando en el rendimiento de la inferencia de tipos.

Antes de cada release, hacemos un benchmark local para asegurarnos de que la inferencia de tipos siempre sea ágil y rápida, y de que no reviente tu IDE con el error "Type instantiation is excessively deep and possibly infinite".

Al escribir con Elysia, casi no te vas a topar con problemas de rendimiento de tipos.

Pero si te pasa, así puedes averiguar qué está frenando tu inferencia de tipos:

1. Ve a la raíz de tu proyecto y ejecuta
```
tsc --generateTrace trace --noEmit --incremental false
```

Esto debería generar una carpeta `trace` en la raíz de tu proyecto.

2. Abre [Perfetto UI](https://ui.perfetto.dev) y arrastra el archivo `trace/trace.json`

![Perfetto](/assets/perfetto.webp)

> Debería mostrarte un flame graph como este

Después puedes buscar un bloque que tarde mucho en evaluarse; haz clic en él y te mostrará cuánto tarda la inferencia, de qué archivo y número de línea proviene.

Esto te ayudará a identificar el cuello de botella de tu inferencia de tipos.

### Eden

Si tienes problemas de lentitud en la inferencia de tipos al usar [Eden](/eden/overview), puedes intentar usar una sub app de Elysia para aislar la inferencia de tipos.

```ts [backend/src/index.ts]
import { Elysia } from 'elysia'
import { plugin1, plugin2, plugin3 } from './plugin'

const app = new Elysia()
	.use([plugin1, plugin2, plugin3])
  	.listen(3000)

export type app = typeof app

// Export sub app
export type subApp = typeof plugin1 // [!code ++]
```

Y en tu frontend, puedes importar la sub app en lugar de la app completa.

```ts [frontend/src/index.ts]
import { treaty } from '@elysia/eden'
import type { subApp } from 'backend/src'

const api = treaty<subApp>('localhost:3000') // [!code ++]
```

Esto debería hacer que tu inferencia de tipos sea más rápida, ya que no se necesita evaluar toda la app.

Echa un vistazo a [Eden Treaty](/eden/overview) para aprender más sobre Eden.
