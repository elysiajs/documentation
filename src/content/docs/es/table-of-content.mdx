### Programar con agentes

Elysia ofrece `llms.txt` y skills para agentes de IA como **Claude Code** y **OpenCode**. Elige una versión de la skill que coincida con la versión de Elysia de tu proyecto.

```
bunx skills add elysiajs/skills
```
