<h1 id="_top">Integración con Netlify Edge Function</h1>

[Netlify Edge Functions](https://docs.netlify.com/build/edge-functions/overview/) se ejecuta en [Deno](/integrations/deno), uno de los runtimes que admite Elysia, ya que Elysia está construido sobre Web Standards.

Netlify Edge Functions necesita una carpeta especial para ejecutar una función; por defecto es **\<directory\>/netlify/edge-functions**.

Para crear una función en **/hello**, tienes que crear un archivo en `netlify/edge-functions/hello.ts` y exportar una función que pase la petición a Elysia.


```typescript title="netlify/edge-functions/hello.ts"
import { Elysia } from 'elysia'

export const config = { path: '/hello' }

const app = new Elysia({ prefix: '/hello' })
	.get('/', () => 'Hello Elysia')

export default (request: Request) => app.handle(request)
```


<span id="running-locally"></span>
### Ejecutar en local
Para probar en local tu servidor de Elysia en Netlify Edge Functions, puedes instalar la [Netlify CLI](https://docs.netlify.com/build/edge-functions/get-started/#test-locally), que simula la invocación de las funciones.

Para instalar la Netlify CLI:
```bash
bun add -g netlify-cli
```

Para arrancar el entorno de desarrollo:
```bash
netlify dev
```

Para más información, consulta la [documentación de Netlify Edge Functions](https://docs.netlify.com/build/edge-functions).

### pnpm
Si tu configuración de pnpm no instala las peer dependencies, añade explícitamente las que necesita Elysia v2:
```bash
pnpm add typebox exact-mirror openapi-types
```
