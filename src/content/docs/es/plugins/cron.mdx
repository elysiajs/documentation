<h1 id="_top">Plugin Cron</h1>

Este plugin te permite ejecutar tareas cron en el servidor de Elysia.

Instálalo con:

```bash
bun add @elysia/cron@rc
```

Después, úsalo así:

```ts
import { Elysia } from 'elysia'
import { cron } from '@elysia/cron'

new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: '*/10 * * * * *',
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.listen(3000)
```

Este código escribe `Heartbeat` en la consola cada 10 segundos.

## cron

Crea una tarea cron para el servidor de Elysia.

Tipo:

```text
cron(config: CronConfig): (app: Elysia) => Elysia
```

`CronConfig` acepta estos parámetros:

### name

Nombre con el que se registra la tarea en `store`.

Registra la instancia de cron en `store` con el nombre que indiques, para que puedas usarla más adelante; por ejemplo, para detener la tarea.

### pattern

Cuándo se ejecuta la tarea, según la [sintaxis de cron](https://en.wikipedia.org/wiki/Cron) que tienes aquí:

```text
┌────────────── second (optional)
│ ┌──────────── minute
│ │ ┌────────── hour
│ │ │ ┌──────── day of the month
│ │ │ │ ┌────── month
│ │ │ │ │ ┌──── day of week
│ │ │ │ │ │
* * * * * *
```

Puedes generarlo con herramientas como [Crontab Guru](https://crontab.guru/).

### run

Función que se ejecuta cada vez que se dispara la tarea.

---

Este plugin registra la tarea programada con [Croner](https://github.com/hexagon/croner).

Estas son las opciones de Croner que admite.

### timezone

Zona horaria en formato Europe/Stockholm

### startAt

Hora de inicio programada de la tarea

### stopAt

Hora de fin programada de la tarea

### maxRuns

Número máximo de ejecuciones

### catch

Sigue ejecutándose aunque la función disparada lance un error no manejado.

### interval

Intervalo mínimo entre ejecuciones, en segundos.

## Detener una tarea cron

Puedes detener la tarea cron manualmente accediendo a ella con el nombre con el que se registró en `store`.

```ts
import { Elysia } from 'elysia'
import { cron } from '@elysia/cron'

const app = new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: '*/1 * * * * *',
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.get(
		'/stop',
		({
			store: {
				cron: { heartbeat }
			}
		}) => {
			heartbeat.stop()

			return 'Stop heartbeat'
		}
	)
	.listen(3000)
```

<span id="predefined-patterns"></span>
## Patrones predefinidos

Puedes importar `Patterns` desde `@elysia/cron`:

```ts
import { Elysia } from 'elysia'
import { cron, Patterns } from '@elysia/cron'

const app = new Elysia()
	.use(
		cron({
			name: 'heartbeat',
			pattern: Patterns.everySecond(),
			run() {
				console.log('Heartbeat')
			}
		})
	)
	.get(
		'/stop',
		({
			store: {
				cron: { heartbeat }
			}
		}) => {
			heartbeat.stop()

			return 'Stop heartbeat'
		}
	)
	.listen(3000)
```

<span id="functions"></span>
### Funciones

| Función                                  | Descripción                                           |
| ---------------------------------------- | ----------------------------------------------------- |
| `.everySeconds(2)`                       | Ejecuta la tarea cada 2 segundos                      |
| `.everyMinutes(5)`                       | Ejecuta la tarea cada 5 minutos                       |
| `.everyHours(3)`                         | Ejecuta la tarea cada 3 horas                         |
| `.everyHoursAt(3, 15)`                   | Ejecuta la tarea cada 3 horas, en el minuto 15        |
| `.everyDayAt('04:19')`                   | Ejecuta la tarea todos los días a las 04:19           |
| `.everyWeekOn(Patterns.MONDAY, '19:30')` | Ejecuta la tarea todos los lunes a las 19:30          |
| `.everyWeekdayAt('17:00')`               | Ejecuta la tarea de lunes a viernes a las 17:00       |
| `.everyWeekendAt('11:00')`               | Ejecuta la tarea los sábados y domingos a las 11:00   |
