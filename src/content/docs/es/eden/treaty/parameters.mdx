<h1 id="_top">Parámetros</h1>

Tarde o temprano vas a tener que enviar un payload al servidor.

Para eso, los métodos de Eden Treaty aceptan 2 parámetros con los que enviar datos al servidor.

Los dos parámetros tienen type safety y TypeScript te guía con ellos automáticamente:

1. body
2. parámetros adicionales
    - query
    - headers
    - fetch

```ts
import { Elysia, t } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia()
    .post('/user', {
        body: t.Object({
            name: t.String()
        })
    }, ({ body }) => body)
    .listen(3000)

const api = treaty<typeof app>('localhost:3000')

// works
api.user.post({
    name: 'Elysia'
})

// also works
api.user.post({
    name: 'Elysia'
}, {
    // This is optional as not specified in schema
    headers: {
        authorization: 'Bearer 12345'
    },
    query: {
        id: 2
    }
})
```

Si el método es **"GET"** o **"HEAD"**:

1. Parámetros adicionales
    -   query
    -   headers
    -   fetch

```ts
import { Elysia } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia()
    .get('/hello', () => 'hi')
    .listen(3000)

const api = treaty<typeof app>('localhost:3000')

// works
api.hello.get({
    // This is optional as not specified in schema
    headers: {
        hello: 'world'
    }
})
```

<span id="empty-body"></span>
## Body vacío
Si el body es opcional o no hace falta, pero sí necesitas query o headers, puedes pasar `null` o `undefined` como body.

```ts
import { Elysia, t } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia()
    .post('/user', {
        query: t.Object({
            name: t.String()
        })
    }, () => 'hi')
    .listen(3000)

const api = treaty<typeof app>('localhost:3000')

api.user.post(null, {
    query: {
        name: 'Ely'
    }
})
```

<span id="fetch-parameters"></span>
## Parámetros de fetch

Eden Treaty envuelve fetch, así que puedes añadir a Eden cualquier parámetro válido de [Fetch](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch) pasándolo en `fetch`:

```ts
import { Elysia, t } from 'elysia'
import { treaty } from '@elysia/eden'

const app = new Elysia()
    .get('/hello', () => 'hi')
    .listen(3000)

const api = treaty<typeof app>('localhost:3000')

const controller = new AbortController()

const cancelRequest = setTimeout(() => {
    controller.abort()
}, 5000)

await api.hello.get({
    fetch: {
        signal: controller.signal
    }
})

clearTimeout(cancelRequest)
```

<span id="file-upload"></span>
## Subida de archivos
Para adjuntar uno o varios archivos, puedes pasar cualquiera de estos:
- **File**
- **File[]**
- **FileList**
- **Blob**

Si adjuntas un archivo, el **content-type** pasa a ser **multipart/form-data**. El esquema de la ruta sigue decidiendo qué tipo de TypeScript se acepta. Con `t.Files()`, convierte el `FileList` de un input en `File[]`; usa un `File` cuando el esquema pida un archivo y no un simple `Blob`.

Supongamos que tienes este servidor:
```ts
// server.ts
import { Elysia, t } from 'elysia'

const app = new Elysia()
    .post('/image', {
        body: t.Object({
            title: t.String(),
            image: t.Files()
        })
    }, ({ body: { image, title } }) => title)
    .listen(3000)

export type App = typeof app
```

Después, sube los archivos desde el cliente:
```ts
// client.ts
import { treaty } from '@elysia/eden'
import type { App } from './server'

const api = treaty<App>('localhost:3000')

const images = document.getElementById('images') as HTMLInputElement

const { data } = await api.image.post({
    title: "Misono Mika",
    image: Array.from(images.files ?? []),
})
```
